安装

一分钟，装好就能用。

运行后只出现在菜单栏，不会显示 Dock 图标。

  1. 1

    拖入“应用程序”

    打开下载好的 DMG，把 XMindAutoSave.app 拖进 Applications。

  2. 2

    首次右键打开

    在“应用程序”中按住 Control 点按 App，选择“打开”，再确认一次“打开”。

  3. 3

    允许辅助功能

    按提示前往“系统设置 → 隐私与安全性 → 辅助功能”，允许 XMindAutoSave。

  4. 4

    点亮开关

    回到 XMind 打开文档，点亮标题栏旁的“自动保存”，这个文件就交给它了。

为什么第一次需要右键打开？

当前版本还没有 Apple 开发者证书，因此无法进行苹果公证。安装包使用 macOS 临时签名并公开全部源码，但 Gatekeeper 仍会在第一次打开时请你手动确认。之后就和普通 App 一样。

常见问题

还有疑问？

找不到答案，可以直接在 GitHub Issues 里提问。

它会读取或上传我的导图内容吗？

不会。程序完全不联网，也不读取导图内容。它只读取 XMind 当前窗口的辅助功能信息（例如文件路径和“已编辑”状态），并且只向 XMind 发送 ⌘S。键盘监听只用来判断“你是否还在输入”，不会记录按下了哪些键。

为什么需要“辅助功能”权限？

macOS 规定，读取其它 App 的窗口信息、以及向其它 App 发送快捷键，都需要“辅助功能”授权。没有这项权限，它就无法知道 XMind 当前打开的是哪个文件，也无法帮你按下 ⌘S。

支持哪些 XMind 版本？

当前版本在 XMind 26.02 上验证，中文和英文界面都可以识别（“已编辑 / Edited”）。它依赖 XMind 的辅助功能界面结构，如果 XMind 以后大幅改版，可能需要同步适配。

设置保存在哪里？怎么卸载？

每个文件的开关记录在 ~/Library/Application Support/XMindAutoSave/preferences.json。卸载时，先在菜单栏取消“登录时自动启动”，退出程序，再删除 /Applications/XMindAutoSave.app；如需清除开关记录，一并删除上面的文件夹即可。

这是 XMind 官方的产品吗？

不是。这是一个独立的社区工具，与 XMind Ltd. 没有隶属或官方合作关系。
